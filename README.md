# Agenda v0.01

基于《Agenda v0.01.pptx》与《Agenda v0.01 策划案.docx》实现的桌面便签/事务管理应用。
技术栈：**Python + PyQt6 + SQLite**，用 PyInstaller 打包为单文件 exe。

> 界面排版为自行设计（未照搬 PPT 坐标），但保留了原稿的信息结构与全部业务规则。

---

## 三、界面说明

- 顶部 5 个分类：待完成 / 已完成 / 延期 / 放弃 / 统计。
  前 4 个是状态筛选（带数量徽标），`统计` 用竖线分隔，属于独立视图。
- **待完成**：便签卡片网格（3 列）。卡片点击进入详情，右上点下拉菜单：重命名 / 取缔。
- **便签详情**：显示待完成事务列表、倒计时（红色）、点下拉菜单（重命名 / 完成 / 预计延期 / 取消）。
- **创建事务必填**：具体内容与 DDL 均为必填（缺失时 toast 提示）。
- **DDL 输入已简化**：不再手打日期文本，改为「所选日期时间」显示框 + 月历（可前后翻月）+ **小时滑条 + 分钟滑条**（可拖动，支持任意时间如 22:45）+ 常用时间快捷按钮（09:00 / 12:00 / 18:00 / 21:00 / 23:00）。默认 DDL 为今天 18:00（已过则取明天）。
- **过去日期不可选**：日历中过去的日期（含今天已过的时刻）置灰且不可点选，点击会提示「不能选择过去的日期，请选择今天或之后的日期」；即使绕过界面把 DDL 设为过去时间，点击「确定」也会被拦截、提示「无法创建：DDL 必须晚于当前时间」且**不会创建事务**。错误信息以红色显示在 DDL 显示框正下方。
- **DDL 状态提示**：显示框右侧显示「今天 / 明天 / 后天 / N 天后 / 已过期」。
- **命名**：创建便签与创建事务均有名称输入框；便签与事务都支持随时重命名（事务在其下拉菜单首项）。
- **输入框可用性**：回车直接提交当前弹窗；打开弹窗时自动聚焦第一个输入框并全选；重绘不会清空已输入内容。
- **分类页**：展示对应状态的事务，附带所属便签名。
- **统计页**：事务总数、完成率、延期率、取消率 + 状态分布饼图 + 月/周新建趋势柱状图。
- **窗口可自由缩放**：拖动窗口边缘即可改变大小，布局自适应（内容区宽度封顶 1080px，便签网格按宽度自动 1~3 列）。最小尺寸 760×600。
- **内容区滚动**：便签列表 / 便签详情事务列表在内容超出时可用鼠标滚轮滚动，右侧显示滚动条。
- **设置按钮**：头部右上角齿轮图标，打开设置面板。
- **桌面实体便签（可选）**：设置里开启后，每个便签会在桌面生成一张独立的黄色实体便签（无边框、置顶），直接显示事务内容与红色倒计时，每秒刷新。
  - 皮肤：经典黄 / 薄荷绿 / 樱粉 / 天蓝 / 石墨灰 5 选 1。
  - 宽度 160~420px 可调，透明度 30%~100% 可调，可选是否显示 DDL。
  - 多张便签按 4×4 网格错位摆放，互不重叠；便签删除时对应窗口自动关闭；双击便签可打开主程序。
  - 桌面便签以独立子进程运行（`Agenda.exe --sticky`），主程序退出不影响其运行。
- **记录管理（每个 tab 都有）**：除「便签详情」页外，顶部 tab 栏右侧都有「管理」按钮。点开进入管理模式：
  - 列表列出该 tab 的记录，左侧复选框可勾选，底部有「已选 N 项」「全选」「删除 N 项」。
  - 「待完成」管理的是**便签**（删除便签会删除其名下**未完成**事务；已结束事务保留在对应分类页并继续计入统计）。
  - 「已完成 / 延期 / 放弃」管理的是对应分类下的**事务记录**。
  - 「统计」页无独立记录，额外提供「清空归档记录」（清空全部已结束记录）。
  - 管理模式下「新建」按钮隐藏，右上角变为蓝色「返回」退出。
  - 切换 tab 会自动退出管理模式。

配色：白底卡片 `#FFFFFF`、页面底色 `#F4F5F7`、主色 `#4874CB`、
成功 `#2E9E68`、危险 `#D93B40`。字体使用微软雅黑（PPT 原稿的 Minecraft AE 未注册，故替换）。

## 四、业务规则（与策划案一致）

| 规则 | 实现 |
| --- | --- |
| 无便签时显示空状态 | 居中圆形 + 号、说明文案、立即创建按钮 |
| 便签默认名「任务 1」 | `db.create_note` 空名兜底 |
| 创建事务必填 | 具体内容、DDL 均为必填，缺失时 toast 提示 |
| 未超时显示红色剩余时间 | `剩余 2天 04:12:08`（精确到秒，每秒刷新） |
| 超时显示已超时 | `已超时 1天 03:00:00`，且菜单不再提供「预计延期」 |
| 未超时完成 → 已完成 | 状态 `done`，卡片显示「按时完成」 |
| 超时后完成 → 延期 | 状态 `delayed` |
| 取消 → 放弃 | 状态 `abandoned` |
| 多次延期按当前倒计时判定 | 延时精确到秒：`delay_seconds` 累加，有效 DDL = 原始 DDL + 累计延时 |
| 延时可指定时长 | 弹窗提供 2小时/6小时/半天/1天/2天/1周 快捷追加，也可自定义「天数 + 小时」直接设定总时长 |
| 显示累计延时 | 事务卡片右下角橙色「已延时 x天x小时」，DDL 行后同步标注 |
| 已完成/延期/放弃移出便签 | 仅 `pending` 留在便签详情页 |
| 删除便签物理删除 | 只删除便签本身及其名下**未完成**事务；已进入「已完成/延期/放弃」的事务**保留**在对应分类页并继续计入统计（以 `note_name` 冗余字段保留原便签名）。`db.delete_note` 先将归档事务 `note_id` 置空保留，再删 pending 事务，最后删便签 |
| 孤儿事务不残留 | `tasks.note_id` 可空且**不使用** `ON DELETE CASCADE`（避免误删归档事务）；`db.purge_orphan_tasks()` 仅清理指向已不存在便签的真正脏数据 |
| 删除前提示 | 「该便签下有 N 个未完成事务（共 M 个事务，含已结束）。删除后未完成事务将无法恢复，已结束事务会保留在分类页并计入统计。确定删除吗？」，M 仅在总事务数大于未完成数时出现 |
| 统计口径 | 只统计已结束事务（done + delayed + abandoned） |

## 五、已知取舍

- 策划案提到的「事务详情二级页」未实现；事务内容直接展示在便签详情页的卡片上。
- 饼图与柱状图为 `QPainter` 手绘，环境无 `PyQt6.QtCharts`。
- 数据库 schema 见 `db.py` 顶部 `init_db()`；`notes` / `tasks` 两表，任务状态字段 `status`。
- 事务名称留空时兜底为「未命名事务」（便签留空兜底为「任务 1」）。
- 延时字段从 `delay_days` 扩展为 `delay_seconds`（秒），旧数据启动时自动按 `delay_days * 86400` 迁移。
- 设置项「鼠标穿透」已持久化但桌面便签暂未实现该行为。
- 皮肤系统目前只作为配置项存在，未做皮肤市场/开源分发相关设计。
